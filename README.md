## ⚡ Core Features

- 📄 **Instant PDF Compilation**: Client-side & server-side rendering of tax-compliant commercial invoices with itemized line items.
- 💱 **Multi-Currency & VAT/GST Calculators**: Automated tax calculation, compound discounts, and shipping adjustments.
- 📬 **One-Click Client Dispatch**: Export to vector PDF, print layouts, or trigger direct email/WhatsApp receipts.

```bash
git clone https://github.com/vickyiitp/Invoice-Flow-Automation-tool.git
cd Invoice-Flow-Automation-tool
npm install
npm run dev
```
